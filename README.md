# 饭点｜南大仙林即时饭搭子

面向南京大学仙林校区学生的轻量应急约饭 Web MVP。

> 当前版本是演示实现：人物、认证、匹配回应、反馈均为虚构模拟数据，不接真实后端，也不使用真实学生信息。

## 本地启动

需要 Node.js 18.17+。

~~~bash
npm install
npm run dev
~~~

浏览器打开 http://localhost:3000。

生产构建验证：

~~~bash
npm run build
npm start
~~~

## 目前已完成

- 首次介绍与模拟校园认证
- 昵称、性别、院系、年级、南大邮箱、兴趣、小头像和简介
- 首页唯一主按钮“找个饭搭子”

- 匹配范围仅提供“不限”和“仅同性”
- 等待状态、等待时长、取消请求
- 只推荐一个候选人；拒绝后重新进入短暂等待
- 双向确认、模拟对方接受和未回应
- 匹配成功后才开放临时聊天、快捷消息和集合点
- 已见面、取消、举报、拉黑
- 饭后“愿意再次一起吃 / 跳过”反馈，不公开星数

## 匹配原则

演示匹配只使用约饭顺利进行所需的信息：

- 地点是否覆盖
- 饮食限制是否冲突
- 预计用餐时长是否接近
- “不限 / 仅同性”范围
- 是否已经拒绝或拉黑
- 新用户和历史可靠性只做很轻的顺序调整

兴趣、专业、年级介绍和当前状态只展示给用户，不进入匹配依据。没有附近的人列表、无限刷人、关注粉丝、排行榜或匹配前聊天。

## 数据接口预留

当前候选人数据位于 lib/mock-data.ts，应用状态位于 lib/types.ts 和 lib/storage.ts。未来接入真实后端时，可以将：

- findCandidate
- handleRequestSubmit
- handleDemoAccept
- handleFeedback

替换为 API 调用，UI 流程无需整体重写。

## 当前仍是模拟的部分

- 校园认证和南大邮箱验证
- 后端账号、请求池和真实实时匹配
- 候选人回应与倒计时
- 聊天消息发送
- 举报、拉黑与反馈的后台存储
- 部署、短信、地图和真实集合点

## 安全边界

这是校园场景的轻量饭局工具，不是约会软件。真实上线前需要补充真实认证、隐私政策、举报审核、风控、未成年人保护和数据删除能力。
